ACCESS TO PROJECT

1. To access my project follow the follwing steps: You need processing 4 (java mode)

2. Open link to my GitHub

3. On GitHub, there are three files names, A2_Abstract, A2_Broadway and A2_Circles

4. Click on A2_Abstract

5. Once this is clicked, click on the file that has been uploaded named, A2_Abstract.pde

6. This will open to my code for the Abstract artwork

7. Once you have this, open Processing 4 (Java mode)

8. Then copy the code from the GitHub into processing

9. Click run at the top left hand corner 

10. The code will run and you will see the artwork

11. This specific artwork (Abstract) is interactive, so click on the screen and it will move

12. To open the two other artworks that I have created, close the Abstract artwork

13. Go back to the home page of Github and repeat steps 3 - 10 - ensuring you click on files: A2_Broadway and A2_Circles
