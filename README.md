To access my project follow the follwing steps:
Open link to my GitHub
On GitHub, there are three files names, A2_Abstract, A2_Broadway and A2_Circles
Click on A2_Abstract
Once this is clicked, click on the file that has been uploaded named, A2_Abstract.pde
This will open to my code for the Abstract artwork
Once you have this, open Processing 4 (Java)
Then copy the code from the GitHub into processing
Click run at the top left hand corner 
The code will run and you will see the artwork
This specific artwork (Abstract) is interactive, so click on the screen and it will move
To open the two other artworks that I have created, close the Abstract artwork
Go back to the home page of Github and repeat steps 3 - 10 - ensuring you click on files: A2_Broadway and A2_Circles
